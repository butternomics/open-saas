# Phase 1 Plan 1: Storage Foundation Summary

Created the `butter-comment-assistant/` src-layout Python package with pinned dependencies, the full status-enum and state-machine contract (`storage/enums.py`), the ten SQLModel tables (`storage/models.py`), programmatic Alembic migration helpers (`storage/db.py`) with the initial `0001_initial_schema` revision, and a pytest harness whose fixtures run real migrations against a temporary SQLite file rather than `create_all`.

## What Was Built

- **Task 1 — Package scaffold**: `pyproject.toml` (PEP 621, setuptools backend, locked deps and dev extras, console script, pytest/ruff config), `.gitignore` for `.venv/`, `data/`, caches and db files, package `__init__.py` files. Bootstrapped `.venv` with `uv venv --python 3.12` + `uv pip install -e ".[dev]"`; `import butter_comment_assistant` and all locked deps import cleanly.
- **Task 2 — Enums and models**: Twelve `(str, Enum)` classes (`CommentStatus`, `DraftStatus`, `OutboundStatus`, `ContextStatus`, `ErrorClass`, `ConnectorKind`, `LLMKind`, `ExampleKind`, `ExampleStatus`, `KnowledgeStatus`, `EvalLabel`, `AuditEvent`), the three transition dicts (`COMMENT_TRANSITIONS`, `DRAFT_TRANSITIONS`, `OUTBOUND_TRANSITIONS`) exactly matching CONTEXT D-10, `assert_transition`/`IllegalTransition`, `utcnow()`, `new_id()`. All ten SQLModel table classes with the exact column sets, PK conventions, JSON columns, and `String(32)` enum columns from D-06 to D-08.
- **Task 3 — Migrations, db helpers, tests**: `storage/db.py` (`PACKAGE_ROOT`, `sqlite_url`, `make_engine`, `run_migrations`, `session_scope`); `alembic.ini` + `migrations/env.py` (imports models, `render_as_batch=True`, `compare_type=True`) + `migrations/script.py.mako`; `migrations/versions/0001_initial_schema.py` creating all ten tables, indexes and the `outbound_tasks.idempotency_key` unique constraint. `tests/conftest.py` (`db_url`, `engine`, `session` fixtures, real migrations only). `tests/test_storage_schema.py` covering table creation, migration idempotency, zero-diff autogenerate, a full JSON-column round trip, a duplicate-idempotency-key `IntegrityError`, every allowed transition in all three tables, every terminal state's absence of outgoing transitions, the two named illegal-transition examples from the plan, and `utcnow`/`new_id` shape checks.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] sqlmodel's default datetime column type rejects naive UTC datetimes**
- **Found during:** Task 3, first `pytest` run
- **Issue:** sqlmodel 0.0.47 maps a bare `datetime` field to its own `UTCDateTime` SQLAlchemy type, which raises `ValueError: Datetime values must have timezone information` when given a naive datetime — exactly what `storage.enums.utcnow()` produces per CONTEXT D-07. Inserting any row with a `created_at`/`updated_at` default failed.
- **Fix:** Annotated every datetime field in `storage/models.py` with pydantic's `NaiveDatetime` instead of bare `datetime`. SQLModel maps `NaiveDatetime` to a plain `DATETIME` SQLAlchemy column with no timezone coercion, so naive UTC values round-trip unchanged, matching D-07 exactly. Regenerated `migrations/versions/0001_initial_schema.py` against the corrected models so the migration and models agree (verified by the zero-diff autogenerate test).
- **Files modified:** `butter-comment-assistant/src/butter_comment_assistant/storage/models.py`, `butter-comment-assistant/migrations/versions/0001_initial_schema.py`
- **Verification:** Full round-trip test (`test_round_trip_insert_and_read`) and zero-diff test (`test_autogenerate_reports_zero_diff`) both pass.
- **Commit:** d99a35a

**2. [Rule 3 - Blocking] ruff UP042 (StrEnum) conflicts with CONTEXT D-09's locked `(str, Enum)` form**
- **Found during:** Task 2, first `ruff check` run
- **Issue:** `ruff check` with `select = ["E", "F", "I", "B", "UP"]` flagged every one of the twelve enum classes with `UP042: inherits from both str and enum.Enum — inherit from enum.StrEnum instead`. CONTEXT D-09 and the plan's `<interfaces>` block explicitly require `class X(str, Enum)`.
- **Fix:** Added `ignore = ["UP042"]` to `[tool.ruff.lint]` in `pyproject.toml` with a comment citing D-09.
- **Files modified:** `butter-comment-assistant/pyproject.toml`
- **Commit:** 5e6f2fd

**Total deviations:** 2 auto-fixed (1 bug, 1 blocking lint conflict). **Impact:** Both are contained to the storage layer and its lint config; no behavior outside `storage/` was touched, and every plan-specified acceptance criterion and interface name is met exactly.
